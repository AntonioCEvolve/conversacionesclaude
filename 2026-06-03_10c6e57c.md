## Mapa de funcionalidades — `/product/calendar`

|---|---|

### Header del calendario
| Elemento | Comportamiento |
|---|---|
| **`<` (flecha anterior)** | Navega al período anterior (mes/semana/día según vista activa) |
| **`>` (flecha siguiente)** | Navega al período siguiente |
| **Hoy** | Vuelve al período actual (hoy resaltado en amarillo) |
| **Título central** | Muestra el período activo ("junio 2026", "1–7 jun 2026", "3 de junio de 2026") |

### Selector de vista (top derecha)
| Vista | Comportamiento |
|---|---|
| **Mes** | Grid mensual 7 columnas, con días numerados y eventos apilados por celda |
| **Semana** | Lista agrupada por día, muestra toda la semana con hora de cada evento |
| **Día** | Lista del día actual con sus eventos y horario |
| **Agenda** | Listado continuo cronológico de todos los próximos eventos |

### Vista Mes — interacciones
| Elemento | Comportamiento |
|---|---|
| **Número del día** (link) | Navega a ese día en vista Día |
| **Evento** (link) | Navega a página de detalle del evento `/product/calendar/:id` |
| **"+N más" / "Mostrar N eventos más"** | Expande la celda inline mostrando todos los eventos del día sin cambiar de vista |
| **Eventos "Festivo"** | All-day events que aparecen como banners azules de ancho completo (multi-día posible) |
| **Día actual** | Resaltado con fondo amarillo |

### Vista Semana / Día / Agenda — interacciones
| Elemento | Comportamiento |
|---|---|
| **Evento** (link) | Navega a detalle del evento |
| **Hora mostrada** | Rango de duración (ej. "18:00 - 21:00") |

### Página de detalle del evento `/product/calendar/:id`
| Sección | Contenido |
|---|---|
| **`← Volver al calendario`** | Back link al listado |
| **Badge "CLASE EN DIRECTO"** | Tipo de evento |
| **"Abrir en Circle"** (botón) | Link externo a la plataforma Circle |
| **Datos de la clase** | Nombre, Cohort (link), Profesor (link), Fecha, Duración, Verificada (Sí/No), Grabación (link), LMS Event ID, Alta |
| **Asistencia** | Lista de alumnos con nombre + email, sincronizada upstream desde Circle (`event_attendees`) |

### Tipos de eventos visibles
| Prefijo / Color | Significado |
|---|---|
| `18 …` / `16 …` | Hora de inicio (18:00 o 16:00) |
| `* ConvXxx…` | Clase en directo marcada/destacada |
| `0 ConvXxx… · Festivo` | Evento all-day festivo |
| Banner azul (span multi-día) | Vacaciones de verano u otros eventos que abarcan varios días |
