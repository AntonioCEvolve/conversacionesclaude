### Claude · 2026-06-22 11:29

El comando añadiría el servidor MCP de **Magnific** vía HTTP (remoto, sin instalación local). Magnific es una herramienta de **upscaling y mejora de imágenes con IA**.

Las posibilidades que abriría en Claude Code:

**Procesamiento de imágenes directamente desde el agente**
- Upscaling de imágenes (x2, x4, x8...) sin salir del flujo de trabajo
- Mejora de detalle, nitidez y coherencia en ilustraciones, fotos, renders
- Reinterpretación de imágenes (creativity slider) — no solo escala, sino que puede añadir/reconstruir detalle

**Aplicaciones para tu flujo Evolve/Ágora**
- Exportar assets de Figma en baja resolución → upscale via Magnific → usar en producción
- Mejorar imágenes de cursos o contenido del LMS antes de subirlas
- Escalar iconos o ilustraciones rasterizadas del sistema de diseño

**Integración con otros MCPs**
- Figma MCP → descarga screenshot → Magnific lo mejora → resultado listo
- Encadenado con tareas de diseño sin cambiar de contexto

**Limitaciones a considerar**
- Es un servicio de pago (API key necesaria probablemente)
- El transporte HTTP remoto depende de que `mcp.magnific.com` esté activo y tu conexión sea estable
- No está documentado públicamente como MCP oficial — conviene verificar que el endpoint es legítimo antes de añadirlo
